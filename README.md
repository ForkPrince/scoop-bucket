# Scoop Bucket

 [![Tests](https://github.com/ForkPrince/scoop-bucket/actions/workflows/ci.yml/badge.svg)](https://github.com/ForkPrince/scoop-bucket/actions/workflows/ci.yml) [![Excavator](https://github.com/ForkPrince/scoop-bucket/actions/workflows/excavator.yml/badge.svg)](https://github.com/ForkPrince/scoop-bucket/actions/workflows/excavator.yml)

A scoop bucket for packages we needed on our systems.

## Install?

```pwsh
scoop bucket add forkprince https://github.com/ForkPrince/scoop-bucket
scoop install forkprince/<manifestname>
```
